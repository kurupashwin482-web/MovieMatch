
# MovieMatch

MovieMatch is a machine learning-based movie recommendation
system developed as part of our course project.

## Recommendation Models

We are developing and evaluating three recommendation approaches:

1. Popularity-Based Recommendation
2. TF-IDF Content-Based Recommendation
3. Genre-Based Recommendation

## Project Structure

- `Backend Artifacts/` - Saved model artifacts and movie metadata.
- `Notebooks/` - Jupyter notebooks for data preparation,
  model development and evaluation.
- `dataset/processed/` - Processed movie datasets.

## Technologies

- Python
- NumPy
- Pandas
- Scikit-learn
- Jupyter Notebook

## Project Status

Machine learning model development and evaluation completed
for the three recommendation approaches.

Backend API and frontend development are planned next.
